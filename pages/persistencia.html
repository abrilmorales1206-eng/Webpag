Definición y características

Persistir es guardar información para que siga disponible después de cerrar la app o apagar el dispositivo. Sus características principales son durabilidad, consistencia, rapidez de acceso y seguridad.

Formas de persistencia en móviles

Archivos

Guardan texto, imágenes o preferencias en el almacenamiento interno o externo. Ejemplos: SharedPreferences, UserDefaults, archivos JSON.

Base de datos local

Almacena datos estructurados dentro del dispositivo, con consultas. Ejemplos: SQLite, Room, Core Data.

Base de datos remota

Los datos viven en un servidor y la app los usa mediante servicios web (REST/JSON). Ejemplos: Firebase, MySQL con API.

Tipos de datos según la persistencia

FormaDatos que almacena
ArchivosConfiguración, texto, JSON, imágenes, audio, documentos
BD localRegistros estructurados: usuarios, tareas, catálogos, historial
BD remotaDatos compartidos entre usuarios y dispositivos: cuentas, pedidos, mensajes

Mecanismos de control de acceso

  • Biblioteca de clases: paquetes listos para leer y escribir datos (por ejemplo, Gson para JSON).
  • Clases de SQLite: en Android, SQLiteOpenHelper crea la base y ejecuta consultas SQL.
  • Mapeo relacional de objetos (ORM): convierte tablas en clases para no escribir SQL a mano (Room, Realm, Core Data).

Autenticación y consumo de servicios web

La app envía usuario y contraseña por HTTPS; el servidor responde con un token (por ejemplo JWT). Ese token se manda en cada petición y la respuesta llega en JSON, que la app convierte en objetos.

data class Tarea(@PrimaryKey val id: Int, val titulo: String)
